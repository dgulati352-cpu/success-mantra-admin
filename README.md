# success-mantra-admin

Official Admin Control Center for **Success Mantra - Class 11 & 12 Commerce Educational Platform** (`https://success-mantra-theta.vercel.app/`).

## Features
- **Executive Overview & Analytics**: Real-time revenue tracking, student growth metrics, subject distribution charts, and pending bookstore orders.
- **Courses & Curriculum Management**: Manage video lectures, chapter breakdowns, and T.S. Grewal & Sandeep Garg PDF solution handouts for Class 11 & 12 Commerce (Accountancy, Economics, Business Studies, Entrepreneurship).
- **Live Studio 2-Teacher Control Desk**: BYJU'S 2-Teacher Advantage model featuring Master Teacher broadcast controls, RTMP stream key generation, live camera/mic/screen studio player, and Assistant Teacher real-time doubt resolution queue.
- **NTA CBT Mock Test Engine**: Create NTA standard CBT exams with +4/-1 marking scheme, question bank builder, step-by-step solutions, and student leaderboards.
- **Official Bookstore & Logistics Fulfillment**: Book catalog management, stock inventory control, and shipping fulfillment with BlueDart & Delhivery tracking.
- **VIP Membership Engine**: Subscription tier pricing, coupon code generator (`CBSE2026`, `VIPFIRST`), and verified subscriber directory.
- **Student Directory & CRM**: Track student test performances, ranks, and toggle VIP access passes.
- **Push Broadcasts & Notifications**: Compose push notifications and update live website header announcement banners.

## Tech Stack
- React 19 + Vite 8
- Tailwind CSS v4
- Lucide React Icons
- Recharts Data Visualization

## Getting Started
```bash
npm install
npm run dev
```
